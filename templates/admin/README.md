# SHW 后台模板

可复制到独立项目的 Vue 3 / TypeScript / Vite 后台应用。demo 也直接运行此目录的源码，框架能力来自 `@shwkj/shw-wui`，不依赖 `@pureadmin/*`。

## 启动

使用 Node 24 和 pnpm 11.0.9。生成器会将已构建的组件库复制到生成项目的 vendor 目录。进入生成的项目目录后，从公共 npm 安装其余依赖。

```sh
pnpm install
pnpm dev
pnpm typecheck
pnpm build
```

构建环境通过 `SOURCE_SHA` 注入来源提交，开发时默认 `local`。生产服务器需要将前端 history 路由回退到 `index.html`。

## 页面与能力

- 登录：`admin / admin123` 可读写；`viewer / viewer123` 只读。页面明确标注模拟环境。
- 首页：入口、当前身份、模拟权限边界、构建来源。
- 标准列表：查询、重置、分页、页签切换保留查询状态、新建/编辑弹窗、删除确认、独立详情页。编辑和详情使用 ID 单独读取，不使用列表行回填。
- 分组表单：独立页面分区、失焦/提交校验、错误聚焦、防重复提交、失败保留输入、离开页面确认。
- 树与列表：静态分类树联动筛选，切换分类回到第一页。
- 403 / 404：只读用户直接访问写入页面可查看 403；未知路径查看 404。

列表名称查询填写“失败”可体验查询错误；新增/编辑名称或分组表单方案名称填写“失败”可体验写入错误。列表记录在内存中，浏览器刷新后恢复初始值；分组表单提交只展示反馈，不持久化。请求带延迟，便于体验 loading 和取消行为。

## 接入自己的项目

菜单中的“页面示例”为多级分组，叶子菜单随当前模拟权限过滤。标准列表开启缓存，关闭其页签后缓存清除；切换页签可保留查询和分页。

`src/main.ts` 注册 Element Plus（中文）、框架样式与 `createAdmin()` 返回的插件；插件内部安装 Router 和 Pinia。`App.vue` 对公开路由渲染 RouterView，对其他页面渲染 ShwAdminLayout（布局内部已有 RouterView）。

1. 修改 `src/admin.ts` 中的标题、页面注册、菜单与权限码。动态详情路由无需放进菜单。路由权限和 ShwPermission 按钮权限一起配置。
2. 替换 `src/mock/session.ts` 的 SessionAdapter。真实实现须使用安全会话机制，按 AbortSignal 取消 restore/login 请求，返回最新 profile 和明确权限列表；logout 清理真实会话。当前 localStorage 仅保存模拟身份，不存密码。
3. 替换 `src/mock/api.ts` 为真实 API。保留 ID/金额字符串契约、详情按 ID 获取、独立响应对象、取消和竞态保护。真实 API 需独立校验身份和权限；当前前端隐藏菜单/按钮和路由拦截不构成后端授权。
4. 替换示例数据结构与业务字段。统一处理真实接口错误、会话失效、超时与授权拒绝，保留提交 loading、防重、失败不清空、关闭脏数据确认（页签离开也复用弹窗关闭确认）、删除对象标识。
5. 根据自己的项目修改命名、存储 key、首页文案，移除模拟账号、失败触发器和所有演示说明。

框架实现和示例应用分别维护；项目通过公开配置、SessionAdapter 与组件插槽扩展，不需要复制修改库内部文件。模板没有真实业务接口，也不宣称已完成后端联调或人工验收。

## 0.3.0 通用组件

菜单“通用组件”实际使用源码接管的配置表格、描述组件和工具入口；标准列表内部也使用同一ShwTable。该页演示初始值不在默认前12项时的已选回显、失败/重试、父依赖就绪与上下文变化、远程树/级联、详情抽屉和加载空态。详情仍按ID独立加载，所有请求仅调用mock adapter。

工具用 import {...} from '@shwkj/shw-wui/utils'；图表单独从 /utils/echarts 引入并按说明注入宿主ECharts，普通模板无需安装图表库。高级表格显式Row类型用createShwTable<Row>()，pagination由父层在事件中更新。完整迁移见库文档。

## 0.4.0 P0 通用组件

通用组件页新增状态色标、危险操作异步确认、文件与图片上传。上传 adapter 仅用浏览器 Object URL 模拟，离开页面失效；替换 upload 函数接入真实服务，成功文件列表由表单持有。可切换失败、父表单禁用并体验取消/重试与预览。

演示首页的「查看登录页」会打开 `/login-preview`，会显示当前是否已登录以及模拟身份，可返回后台或退出后进入实际登录页。实际登录入口为 `/login`，首页和右上角账户菜单均可退出。刷新时先恢复会话，再决定显示受保护页面还是跳转登录。项目品牌与登录适配器由使用方配置。
