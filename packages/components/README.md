# @shwkj/shw-wui

Vue 3 and Element Plus components for desktop administration applications. This package provides the admin shell, tables, filters, forms, descriptions, permission helpers and the starter generator.

Import components from `@shwkj/shw-wui` and include `@shwkj/shw-wui/style.css` in the host app. The library also exports utility functions from `@shwkj/shw-wui/utils` and the optional ECharts integration from `@shwkj/shw-wui/utils/echarts`.

To create a standalone example from a GitHub checkout, run `pnpm build` at the root and then `node packages/components/bin/create.mjs ../my-admin`. See the repository README for prerequisites.
