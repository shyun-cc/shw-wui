> **设计讨论稿 · 尚未实现。**

以下仅用于描述设计文档，**不是数据库表、TypeScript 类型或已存在的运行时模型**。字段、关联及是否采用均待确认。

| 概念 | 候选信息 | 关联 |
| --- | --- | --- |
| 组件说明 | 名称、职责、适用及不适用场景 | 对应多个状态和验收条目 |
| 状态说明 | 状态名称、触发条件、视觉与交互结果 | 属于某个组件说明 |
| 使用场景 | 使用者、任务、输入、成功与失败结果 | 可使用多个组件 |
| 验收条目 | 前置条件、操作、预期结果、验证方法 | 关联场景或组件 |
| 设计决策 | 状态、问题、候选项、结论、影响 | 引用问题和受影响说明 |

是否需要设计变量、组合规则、版本兼容信息等概念，待首批场景确认后补充。本阶段没有数据持久化需求的证据，不设计表结构或迁移。
